## Resume length

Every resume must be exactly one page. Render the final DOCX to PDF, check the actual PDF page count equals 1, and visually inspect that page before delivery, marking Ready, dashboard upload, or application attachment. Repeat the check after every edit; a template, DOCX page-count property, or older render is not proof. If it overflows, shorten or remove lower-priority grounded content while preserving readable typography and the base layout. Never clip text, hide overflow, or shrink it into unreadability. If it is under-filled, add only relevant verified content; never pad or invent facts. Record `PAGE_COUNT: 1` and `LAYOUT: PASS (1 page)` in the tailoring report only after validation.
